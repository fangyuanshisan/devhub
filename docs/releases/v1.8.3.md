# DevHub v1.8.3：后台插件治理页面稳定性与中文体验优化版

[返回文档入口](../README.md)

日期：2026-05-18

## 版本定位

v1.8.3 定义为“后台插件治理页面稳定性与中文体验优化版”。

本轮只优化后台插件治理页面稳定性、页面结构、页内 Tab、详情抽屉分组、中文文案、空状态、危险操作提示和安全边界说明；不修改插件底层生命周期逻辑，不修改 Webhook 协议，不修改 Secret / Callback Token 安全模型。

## 已完成

### v1.8.3-S7：official_announcement 浏览器回归固定测试种子 / fixture

- `scripts/check-admin-plugin-ia.sh` 新增 `official_announcement` fixture 前置步骤：先通过 `/api/v1/admin/login` 获取真实后台 token，再用现有后台插件 API 幂等确保官方公告插件全局启用、PHP 或首个可用子站启用。
- fixture 默认配置固定为：`enabled=true`、`message="欢迎使用 DevHub 官方公告插件"`、`link_text="查看详情"`、`link_url="/"`、`dismissible=false`。
- fixture 多次执行时会先比较全局 / 子站配置；配置一致时跳过重复写入，减少配置版本和审计噪音。
- 浏览器回归不再在缺少数据时跳过 `official_announcement`，而是强制覆盖插件列表、详情概览、公告配置、前端挂载、公告预览和 1366 宽度详情截图；报告会记录 fixture 准备结果。
- 回归脚本校验公告预览 iframe 仍使用内置 `/plugins/official-announcement/iframe`，`sandbox="allow-scripts"`，且 iframe DOM 不包含 callback token、webhook secret、token_hash、authorization、secret/token query。
- 修复官方挂载 Host helper 后台预览鉴权：admin area 读取 context / 写 audit 时使用后台 sessionStorage 中的 admin token 作为 Host 请求 Authorization，但 token 仅留在 Host 层，不传入 iframe，不改变 Host + iframe + postMessage 协议。
- fixture 通过现有后台 API 适配 MemoryStore 与 MySQLStore；不新增生产 API，不改变插件底层生命周期、Webhook 协议、Secret / Token 安全模型，不开放远程 iframe，不执行第三方代码，不做 blocking Hook。

### v1.8.3-S6：插件详情抽屉性能拆包与 1024 宽度视觉回归

- `PluginConfigVersionsDialog` 从详情抽屉主路径改为 `defineAsyncComponent` 按需加载，配置版本弹窗打开前不进入详情抽屉首屏同步加载路径。

- 配置编辑器中的 `json-editor-vue` 改为仅在用户切到 JSON 模式时动态加载；默认表单模式不再同步拉取重型 JSON 编辑器。
- 配置版本弹窗宽度改为 `min(94vw, 980px)`，详情 / 回滚预览抽屉改为 `min(94vw, 760px)`；列表和 diff 表格补充中文空状态，JSON / diff 折叠标题改为中文。

- 扩展 `scripts/check-admin-plugin-ia.sh`：除 5 个治理域和旧路由外，新增 1024 宽度普通插件详情、配置 Tab、技术详情折叠、配置版本弹窗截图；1366 宽度继续回归治理域页面。

### v1.8.3-S5：插件详情抽屉视觉 polish 与信息减负

- 插件详情抽屉可见 Tab 收敛为：概览、配置、前端挂载、Webhook、安全凭据、运行记录、审计日志、技术详情；低频技术入口不再与高频治理入口平级堆叠。
- 概览 Tab 只展示插件身份、状态、能力摘要和风险边界，补充“是否执行第三方代码：否”“允许远程 iframe URL：否”“Webhook 能力”“回调 Token 不展示明文”等摘要。
- 配置 Tab 改为生效配置摘要 + 编辑入口：展示配置来源、生效字段、配置模型和校验状态；原始配置模型、当前配置 JSON、生效配置快照统一进入技术详情。
- 前端挂载 Tab 补充 iframe 路由、sandbox、postMessage、挂载位置、远程 URL、第三方代码执行和凭据暴露说明；`official_announcement` 可直接进入公告预览。
- Webhook Tab 仅保留当前插件摘要和跳转入口，不复制全局 Events / Deliveries / Retry / Circuit Breaker 表格。
- Webhook 密钥和回调 Token 收敛到“安全凭据”Tab，明确 secret_ref / token_ref、权限范围、轮换 / 禁用 / 吊销入口以及明文只展示一次的规则。
- 技术详情 Tab 默认折叠，收纳 config_schema、resolved_config、config_json、内容类型、权限、前端挂载声明、Webhook / Hook 声明、依赖和运行健康原始摘要；展示前对 token / secret / authorization / signature / token_hash / hmac 字段脱敏。
- 审计详情和 Hook 执行详情中的 JSON 元数据展示同样做敏感字段脱敏，避免 token_hash、Authorization Header 或完整 HMAC signature 在详情抽屉中裸露。
- `official_announcement` 的公告配置、前端挂载、公告预览入口更直观，继续说明官方内置、只允许内置 iframe、不执行第三方代码、不暴露 callback token / webhook secret。
- 本批次只调整后台 UI 和文档，不改变 API、插件生命周期、Webhook 协议、Secret / Token 安全模型，不开放远程 iframe、第三方代码执行或 blocking Hook。

- 左侧插件导航最终收敛为 5 个治理域：插件总览、插件包治理、Webhook 治理、发布者与信任、运行记录 / 审计，不再直接展示 20+ 个低频入口。
- 新增治理域容器页：`PluginOverviewDomain`、`PluginPackagesDomain`、`PluginPublishersDomain`、`PluginRuntimeDomain`，通过页内 Tab 承接原入口。
- 插件总览域包含：总览、插件列表、配置中心、前端挂载、内容治理、权限矩阵、开发者工具。
- 插件包治理域包含：远程索引、远程包下载、暂存上传包、本地包与预检、依赖 / 兼容性、版本与升级、安装 / 升级审批；并保留远程索引、暂存区、预检、启用前检查、升级不执行第三方代码的说明。
- Webhook 治理域新增“Webhook 总览”Tab，并继续保留事件通知、投递记录、重试队列、熔断状态、Webhook 密钥、回调 Token、回调请求；空数据安全默认值仍保留。
- 发布者与信任域包含：发布者列表、公钥 / key_id、可信级别、影响分析、密钥轮换；依赖 / 兼容性已归入插件包治理。
- 运行记录 / 审计域包含：操作历史、审计日志、Hook 排障、搜索索引、最近错误；最近错误只提供排障入口说明，不重复展示完整全局表格。
- 旧插件路由保持兼容并重定向到新治理域和对应 `?tab=`：例如 `/plugins/list` -> `/plugins/overview?tab=list`，`/plugins/install` -> `/plugins/packages?tab=install`，`/plugins/events` -> `/plugins/webhooks?tab=events`，`/plugins/trusted-publishers` -> `/plugins/publishers?tab=list`，`/plugins/operations` -> `/plugins/runtime?tab=operations`。
- `PluginInstallUpgrade` 的内部工作区 Tab 改为 `workspace_tab`，避免与治理域三级 Tab 的 `tab` query 冲突；旧 `/plugins/install?tab=template` 会兼容到 `/plugins/packages?tab=install&workspace_tab=template`。
- 插件后台公共筛选条改为“标题说明在上、筛选条件网格排布、按钮随条件同行”的紧凑布局，避免宽屏下输入框被拉满成纵向长条。
- 插件模块保留左侧二级导航，但调整为“插件管理”分组下直接展示 5 个治理域入口，避免 5 个单项分组造成左侧栏视觉空洞。
- 本批次只调整后台页面 IA、导航、Tab 与中文说明，不改变插件生命周期、Webhook 协议、Secret / Token 安全模型，不开放远程 iframe、第三方代码执行或 blocking Hook。

- 左侧插件导航收敛为 5 个治理域：插件总览、插件包治理、Webhook 治理、可信发布者、运行记录 / 审计；旧路由仍保留并归入对应治理域。

## 安全边界

- 仍不开放远程 iframe URL。
- 仍不执行第三方插件代码。
- 仍不做 JS 注入。
- 仍不开放插件市场。
- 仍不做 blocking Hook。
- Webhook Secret 和 Callback Token 明文仍只展示一次，列表和详情不展示明文。
- Callback Token 仍不是管理员权限，只能访问授权 Scope。
- 停用插件会停止前端挂载和 Webhook 投递；软卸载保留历史数据但停止新能力。

## 未改变

- 插件生命周期底层逻辑未改变。
- Webhook delivery / retry / circuit breaker 核心逻辑未改变。
- Secret / Callback Token 安全模型未改变。
- Host + iframe + postMessage 协议未改变。
- `/topics/:id` SEO、`/c/:slug` SEO、`sites/posts` 兼容 API 未改变。
