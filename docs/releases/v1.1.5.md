# DevHub v1.1.5 - 前台 UI 美化专项

[返回文档大纲](../README.md)

发布日期：2026-05-10

## 版本定位

DevHub v1.1.5 是“前台 UI 美化专项”。本版本在不改变前台模块、接口、业务逻辑、路由、鉴权、数据库和 SEO 结构的前提下，统一优化前台视觉体验，让 DevHub 前台更接近成熟技术社区产品。

本补丁已并入当前 v1.2.0 工作分支；不回退 `VERSION`。

## 完成内容

- 统一前台 CSS 变量，补齐主色、辅助色、成功 / 警告 / 危险色、背景、卡片、边框、阴影、圆角和响应式宽度变量。
- 优化全局页面背景、字体层级、链接 hover、焦点态和容器宽度。
- 优化顶部导航、Logo、子站切换、搜索框、登录态用户菜单、发布按钮和版主入口的视觉层级。
- 优化首页聚合区、子站推荐、精选内容、右侧栏和空状态样式。
- 优化子站页 header、板块导航、排序 tab、关注 / 发帖按钮、统计和侧边栏模块样式。
- 优化 Topic 列表卡片、内容类型徽章、子站 / 板块标识、标签、状态徽章、摘要和统计信息。
- 优化 Topic 详情页标题、面包屑、正文排版、代码块、引用、表格、标签、互动按钮和评论区样式。
- 优化搜索页筛选区、搜索条件摘要、结果列表和分页样式。
- 优化发布页表单、输入框、标签选择、错误 / 成功提示和侧栏说明样式。
- 优化我的收藏、我的关注、我的动态、通知页的卡片、空状态和未读状态。
- 优化 `/moderator` 版主工作台入口和 MVP 页面已有卡片 / 筛选 / 统计样式，但不改变权限或接口。
- 补充移动端响应式规则，改善导航、搜索、首页、子站页、Topic 卡片、Topic 详情页和发布页在小屏下的可读性。

## 未改变内容

- 未修改 Go 后端业务逻辑。
- 未新增或修改 API。
- 未修改 Store 或数据库 schema。
- 未修改前台路由和后台 admin-next。
- 未修改前台登录、关注、发布、评论或版主权限逻辑。
- 未修改 `/topics/:id`、`/c/:slug`、`/tags/:tag` 的 Go 动态 SEO 输出结构。
- 未删除 `sites/posts` 兼容 API。

## SEO 保护

本轮只改 Astro 前台全局样式文件和文档。`/topics/:id`、`/c/:slug` 和 `/tags/:tag` 仍由 Go 动态输出 SEO HTML；标题、description、canonical、h1、正文 / 内容链接和标签链接的职责不变。

## 已知限制

- v1.1.5 不是完整设计系统重构，未拆分组件库或主题配置后台。
- 视觉验收仍建议结合真实浏览器截图检查桌面端和移动端细节。
- 深色主题做了基础适配，但还不是独立主题专项。
- 更细的图标体系、品牌资产、骨架屏和设计 token 文档可在后续版本继续完善。

## 后续规划

- 建立更正式的前台组件样式规范和视觉回归截图清单。
- 增加更完整的移动端导航交互优化。
- 后续如引入主题系统，应继续保持 `/topics/:id` 和 `/c/:slug` 的 Go 动态 SEO HTML 不退化。
