# DevHub v1.2.0 - 标签系统增强版

[返回文档大纲](../README.md)

发布日期：2026-05-09

## 版本定位

DevHub v1.2.0 是“标签系统增强版”。本版本把标签从基础筛选条件升级为可管理、可关注、可 SEO 收录的内容聚合入口。

## 本版本完成内容

- 标签页：`/tags/:tag/` 由 Go 动态输出标签聚合 SEO HTML。
- 标签详情 API：`GET /api/v1/tags/:tag`。
- 标签下内容聚合：`GET /api/v1/tags/:tag/topics`，支持 `community_slug`、`sort`、分页。
- 标签关注：复用 `POST /api/v1/follows/toggle`，`target_type=tag`，更新 `follower_count`。
- 发布页标签建议：`GET /api/v1/tags/suggestions`，按当前子站返回启用标签。
- 后台标签 CRUD：`/admin-next/tags` 和 `/api/v1/admin/tags`。
- 标签启用 / 禁用：`POST /api/v1/admin/tags/:id/enable`、`disable`。
- 标签 SEO 字段：`seo_title`、`seo_description`、`seo_keywords`。
- 标签关联内容查看：`GET /api/v1/admin/tags/:id/topics`。
- sitemap 标签收录：启用标签进入 `/sitemap.xml`，禁用标签不收录。

## 数据结构变化

`tags` 表新增或确认以下字段：

```text
status VARCHAR(32) DEFAULT 'enable'
follower_count INT UNSIGNED DEFAULT 0
seo_title VARCHAR(255) DEFAULT ''
seo_description VARCHAR(500) DEFAULT ''
seo_keywords VARCHAR(500) DEFAULT ''
```

MemoryStore 新增真实标签实体映射，MySQLStore 新增启动补字段逻辑。新库可直接使用 `db/mysql/001_schema.sql` 初始化，旧库启动时会尽量补齐字段并把旧状态值转换为 `enable/disable`。

## API 范围

公开 API：

- `GET /api/v1/tags`
- `GET /api/v1/tags/hot`
- `GET /api/v1/tags/suggestions`
- `GET /api/v1/tags/:tag`
- `GET /api/v1/tags/:tag/topics`
- `POST /api/v1/follows/toggle`，请求 `{"target_type":"tag","target_id":1}`

后台 API：

- `GET /api/v1/admin/tags`
- `POST /api/v1/admin/tags`
- `GET /api/v1/admin/tags/:id`
- `PUT /api/v1/admin/tags/:id`
- `GET /api/v1/admin/tags/:id/topics`
- `POST /api/v1/admin/tags/:id/enable`
- `POST /api/v1/admin/tags/:id/disable`

## 前台范围

- Topic、子站、搜索、收藏列表中的标签链接指向 `/tags/:tag/`。
- 发布页按所选子站加载标签建议，最多选择 5 个标签。
- 标签页展示标签名称、说明、内容数、关注数、所属子站、最新内容、热门内容、精华内容和相关标签。
- 标签页提供关注按钮和发布入口。

## 后台范围

`/admin-next/tags` 支持：

- 标签列表、子站筛选、状态筛选和关键词搜索。
- 新增 / 编辑标签。
- 启用 / 禁用标签。
- 配置描述和 SEO 字段。
- 打开前台标签页。
- 查看标签关联内容。

## SEO 范围

- `/tags/:tag/` 由 Go 动态输出 HTML，不依赖纯 CSR。
- 标签页 HTML 包含 title、meta description、canonical、h1、标签说明、内容链接和相关标签链接。
- canonical 使用 `/tags/:slug/`。
- `/sitemap.xml` 收录启用标签。
- 禁用标签返回 404/noindex，不进入 sitemap。
- `/topics/:id` 和 `/c/:slug` SEO 未改变职责，仍由 Go 动态输出。

## 不做内容

- 不做标签合并。
- 不做标签别名。
- 不做标签趋势统计。
- 不做推荐算法。
- 不做声望积分。
- 不做复杂运营分析。

## 已知限制

- 标签合并、标签别名和标签趋势统计留到后续版本。
- 标签页当前按 slug 查找；未来合并/别名需要新增重定向和 canonical 策略。
- sitemap 仍是单文件动态输出，内容量扩大后需要分片。
