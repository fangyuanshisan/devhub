## 版本定位

v1.9.0 定义为“官方插件生态稳定版”。本版本从 v1.8.4 的 release candidate 继续推进，目标是稳定已经存在的官方插件生态、SecretCenter / `external_service` / Webhook 运维闭环、插件包治理、后台 IA、MySQLStore 生产模式和验收文档。

发布归档结论：DevHub v1.9.0 官方插件生态稳定版已完成发布归档与发布后 targeted smoke，P0=0，P1=0，P2=0，版本可以冻结。建议先提交当前文档归档，再创建 v1.9.0 annotated tag。v1.9.0 冻结后，项目进入下一阶段规划；不再向 v1.9.0 追加新功能。`v1.9.1` 是维护候选，面向小修、文档、测试和兼容性；`v1.10.0` 是规划阶段，面向更大的功能、治理和架构演进。

v1.9.0 不是动态插件运行时版本：不执行第三方插件代码，不开放 Go plugin、JS sandbox、WASM、Lua sandbox、远程 iframe、remote component、任意远程 JS、插件市场、远程在线安装、blocking Hook、package scripts、自动安装或自动启用。Webhook Secret / Callback Token 安全模型不变；`DEVHUB_PLUGIN_CONFIG_KEYS` 不落库；token / secret / Authorization / root key / `encrypted_value` 不回显；`migrations/` 仍是唯一迁移入口，dry-run 不执行 SQL。
