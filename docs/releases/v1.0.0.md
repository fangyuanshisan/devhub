# DevHub v1.0.0 Release Notes

[返回文档大纲](../README.md)

发布日期：2026-05-09

## 版本定位

DevHub v1.0.0 是第一个可运行的大版本归档。它把前八轮迭代整理为一个可以启动、测试、部署、备份、回滚和继续演进的社区 CMS 基线。

## 主要能力

- 多子站社区：总站、PHP、Go、Java、AI、Frontend。
- 内容系统：Topic 发布、列表、详情、编辑、删除、标签、浏览和热门排序。
- 搜索筛选：关键词、子站、内容类型、标签、精华、未解决问答。
- 互动闭环：点赞、收藏、关注、我的收藏、我的关注、我的动态和通知中心。
- 评论问答：评论、回复、评论通知、评论动态、采纳最佳答案、已解决 / 未解决状态。
- 社区治理：Topic / Comment 举报、版主权限、精华、置顶、隐藏、恢复、评论锁定。
- admin-next：内容 CRUD、评论管理、举报处理、版主管理、批量治理、治理审计日志。
- SEO：`/topics/:id` 由 Go 动态输出百度友好的 HTML，`/sitemap.xml` 和 `/robots.txt` 动态输出。
- 存储：MemoryStore 和 MySQLStore 双模式，MySQL 8 schema 已覆盖 v1.0.0 主线能力。

## 快速启动

推荐开发启动：

```bash
./dev.sh --restart
```

二进制兜底启动：

```bash
mkdir -p .devhub
go build -o .devhub/devhub .
PORT=8090 CMS_STORE=memory ./.devhub/devhub
```

访问入口：

```text
前台：http://127.0.0.1:8090/
后台：http://127.0.0.1:8090/admin-next
```

## 部署方式

- 默认端口：`8090`，可通过 `PORT` 覆盖。
- 开发默认数据模式：`CMS_STORE=memory`。
- MySQL 模式：`./dev.sh --mysql`，开发库由 `docker-compose.dev.yml` 提供 MySQL 8。
- 前台构建：`cd web/frontend-app && FRONTEND_SITE_URL=http://127.0.0.1:8090 npm run build`。
- 后台构建：`cd web/admin-app && npm run build`。
- 本机没有 `npm` 时，可使用 `dev.sh` 的 Docker Node 构建流程或按 `docs/DEPLOYMENT.md` 中的 Docker Node 命令执行。
- 生产环境建议使用进程守护、反向代理、HTTPS、日志轮转和定期数据库备份。

## 测试清单

归档前建议至少执行：

```bash
go test ./...
go build -o .devhub/devhub .
cd web/frontend-app && npm ci && FRONTEND_SITE_URL=http://127.0.0.1:8090 npm run build
cd web/admin-app && npm ci && npm run build
```

本机无 `npm` 时，用 Docker Node 构建替代前后台 `npm` 命令。详细测试矩阵见 `docs/TESTING.md`。

基础 URL：

```text
/
/admin-next
/admin-next/content
/admin-next/comments
/admin-next/reports
/admin-next/moderators
/admin-next/audit-logs
/topics/1
/sitemap.xml
/robots.txt
```

SEO 回归必须确认 `/topics/:id` 源码包含 `title`、`meta description`、`h1`、正文摘要或正文、标签链接和发布时间，且不是纯 CSR 空壳。

## 已知限制

- 标签系统仍是基础能力；v1.1.0 已改为子站模块增强版，标签详情 SEO 页、标签后台管理、标签合并 / 别名和趋势统计顺延到 v1.2.0。
- 评论点赞未进入 v1.0.0 主线。
- 问答支持采纳和更换最佳答案，暂不支持取消已解决状态。
- 标签关注、用户关注已有后端基础，前台入口仍可继续增强。
- sitemap 当前未做大规模分片。
- migration 仍以基础 SQL 和少量迁移脚本为主，生产升级需要先在预发库演练。

## 下一版本规划

后续版本建议聚焦：

- v1.1.0：子站模块增强，独立首页、SEO、配置、板块、版主、统计、关注和公告。
- v1.2.0：标签专项增强，标签详情页、标签 SEO 聚合页、标签后台管理、标签合并 / 别名。
- 推荐和相关内容。
- sitemap 分片和更完整 canonical 策略。
- 运营分析和治理统计看板。
- 评论点赞和问答取消已解决状态。

```bash

git diff

```
