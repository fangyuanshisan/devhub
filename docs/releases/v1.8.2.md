# v1.8.2：iframe / sandbox 通用容器与 postMessage SDK 版

更新时间：2026-05-18

本版本在 v1.8.1 “官方公告插件前端挂载最小实现”基础上，将 `official_announcement` 的 Host + iframe + postMessage 挂载逻辑抽取为可复用的 **官方插件前端挂载基础能力**（第一阶段仅 allowlist 官方内置插件，不支持任意远程 iframe URL）。

本轮完成后，项目文档为长期状态来源；聊天回复仅作为摘要。

## 1. 本轮目标

1. 抽取通用 iframe Host 容器逻辑（校验 mount_id / plugin_code / message type / origin / source）。
2. 抽取通用 postMessage message schema（ready/context/config.read/audit.write）。
3. 前台 Astro 首页复用通用 helper，减少插件挂载脚本复制。
4. `/c/:slug` Go SEO 动态页复用通用 helper，减少内联脚本复制并保持 SEO 红线。
5. 后台插件详情页复用通用 iframe mount 组件。
6. `official_announcement` 迁移为基于通用容器运行。
7. 保持安全边界：不向浏览器/iframe 暴露 callback token / webhook secret；不允许远程 iframe URL；不执行第三方不可信代码。

## 2. 已实现（真实落地）

### 2.1 通用 Host helper（后端内置静态资产）

- 新增后端内置 JS helper：
  - `GET /plugins/assets/devhub-plugin-mount-host.js`
- helper 职责：
  - 仅允许官方插件 allowlist（第一阶段仅 `official_announcement`）。
  - 统一 iframe 创建与 sandbox 策略（默认 `sandbox="allow-scripts"`）。
  - 统一 postMessage 校验：
    - `event.source` 必须为当前 iframe `contentWindow`
    - `event.origin` 必须等于当前站点 origin
    - `schema_version/type/plugin_code/mount_id` 必须匹配
    - message type 必须在白名单内（ready/config.read/audit.write）
  - 统一桥接：
    - `config.read`：通过 Host API 返回 browser-safe config
    - `audit.write`：通过 Host API 写入 `official_announcement.*` 审计
- 安全边界：
  - helper 不从第三方域名加载脚本
  - helper 不向 iframe 注入任何 token/secret
  - helper 不允许前端传入任意 iframe URL（iframe 路径由 allowlist 内置映射决定）

### 2.2 前台首页复用 helper（Astro）

- 首页挂载点改为通用数据属性：
  - `data-devhub-plugin-mount`
  - `data-plugin-code="official_announcement"`
  - `data-area="frontend"`
- 首页通过 `<script src="/plugins/assets/devhub-plugin-mount-host.js" defer></script>` 引入 helper，避免复制大段挂载脚本。

### 2.3 `/c/:slug` 子站 SEO 页复用 helper（Go 动态 HTML）

- 子站页挂载点改为通用数据属性并携带子站上下文：
  - `data-devhub-plugin-mount`
  - `data-plugin-code="official_announcement"`
  - `data-area="frontend"`
  - `data-community-slug="{slug}"`
- 子站页通过 `<script src="/plugins/assets/devhub-plugin-mount-host.js" defer></script>` 引入 helper。
- 说明：子站页仍由 Go 输出 SEO 动态 HTML，`title/canonical/JSON-LD/h1/主体内容` 保持不变。

### 2.4 后台插件详情复用组件

- 新增后台通用组件：`web/admin-app/src/components/plugin/PluginIframeMount.vue`
  - 懒加载共享 helper `/plugins/assets/devhub-plugin-mount-host.js`
  - 用同一套机制挂载官方插件 iframe
- `PluginDetailDrawer` 的 `official_announcement` “公告预览”Tab 迁移为使用 `PluginIframeMount` 组件。

## 4. 安全边界（口径收口）

1. iframe 仅允许仓库内置页面路由，不支持配置任意远程 URL。
2. 不向浏览器/iframe 暴露 callback token / webhook secret / admin token。
3. postMessage 必须校验 origin/source/plugin_code/mount_id/type 白名单。
4. 挂载受 plugin enabled/soft_uninstalled 与 community plugin enabled 约束（由 Host API 强校验）。
5. SEO 红线：`/topics/:id` 与 `/c/:slug` 仍保持 Go 动态 SEO 输出兜底，不被 CSR 空壳替代。
