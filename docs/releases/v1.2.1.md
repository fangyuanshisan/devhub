# DevHub v1.2.1 - 标签合并、别名与统计重算版

[返回文档大纲](../README.md)

发布日期：2026-05-10

## 版本定位

DevHub v1.2.1 是“标签合并、别名与统计重算版”。本版本在 v1.2.0 标签页、标签 SEO、标签关注、后台标签 CRUD 和 sitemap 收录的基础上，继续补齐标签治理能力。

## 本版本完成内容

- 标签别名：支持为标签配置多个别名，支持后台查看 / 添加 / 删除，支持发布页标签建议按 alias 命中主标签。
- 标签解析：`/tags/:slug/`、`/c/:slug/tags/:slug/`、标签详情 API、标签 suggest API 和搜索 tag 参数都支持 alias 归一。
- 标签合并：支持把 source tag 合并到 target tag，source tag 进入 `merged` 状态并写入 `merged_to_id`。
- 关联迁移：合并时迁移 `topic_tags`、去重后迁移 `follows`，并把 source tag 的 alias 迁移到 target tag。
- 标签统计重算：支持后台单个标签重算和全部标签批量重算，统计至少覆盖 `topic_count`、`follower_count`、`hot_score`。
- 标签治理审计：标签别名、新增 / 删除别名、标签合并、单个 / 批量重算都写入后台 audit logs。
- 后台增强：`/admin-next/tags` 支持状态筛选、别名管理、合并标签、合并确认和统计重算。

## 数据结构变化

当前真实实现继续沿用 `tags.site_key` 作为子站范围字段，而不是额外引入 `community_id` 到 `tags` 表。

`tags` 表新增或确认：

```text
status VARCHAR(32)            -- enable / disable / merged
merged_to_id BIGINT NULL
hot_score INT UNSIGNED
```

`tag_aliases` 表新增：

```text
id
tag_id
site_key
alias
alias_slug
created_at
updated_at
```

唯一约束：

- `uk_tags_site_slug (site_key, slug)`
- `uk_tag_aliases_site_alias_slug (site_key, alias_slug)`

## 状态规则

- `enable`：启用标签，可被前台建议、搜索、SEO 页面和 sitemap 使用。
- `disable`：禁用标签，不进入 sitemap，前台访问返回不可用页。
- `merged`：已合并标签，不进入建议、热门、默认后台列表和 sitemap；访问时 301 到目标标签。

## 别名规则

- alias 不能为空，当前实现限制为 1 到 50 个字符。
- alias_slug 由 alias 规范化生成。
- alias_slug 不能与同 `site_key` 下任何 `tags.slug` 冲突。
- alias_slug 不能与同 `site_key` 下任何其他 `tag_aliases.alias_slug` 冲突。
- 仅 `enable` 标签允许新增别名。
- alias URL 不进入 sitemap。

## 合并规则

- source tag 与 target tag 不能相同。
- 仅支持同一 `site_key` 范围内合并。
- target tag 必须是 `enable`，不能是 `disable` 或 `merged`。
- source tag 合并后写入 `status=merged` 与 `merged_to_id=target.id`。
- `topic_tags` 迁移到 target 后通过 `INSERT IGNORE` / 去重逻辑避免重复。
- `follows` 迁移到 target 后按 `(user_id,target_type,target_id)` 唯一键去重。
- source tag alias 迁移到 target；冲突 alias 不重复保留。
- 合并完成后重算 target tag；merged source 统计归零。

## API 范围

公开解析增强：

- `GET /api/v1/tags/:tag`
- `GET /api/v1/tags/by-slug/:tag`
- `GET /api/v1/communities/:slug/tags/:tag`
- `GET /api/v1/tags/suggestions`
- `GET /api/v1/tags/suggest`
- `GET /api/v1/search/topics?tag=...`

后台新增：

- `GET /api/v1/admin/tags/:id/aliases`
- `POST /api/v1/admin/tags/:id/aliases`
- `DELETE /api/v1/admin/tags/:id/aliases/:aliasId`
- `POST /api/v1/admin/tags/:id/merge`
- `POST /api/v1/admin/tags/:id/recalculate`
- `POST /api/v1/admin/tags/recalculate-all`

## SEO 与 sitemap

- alias URL 与 merged source URL 优先 301 到 canonical 主标签 URL。
- disabled / merged 标签不进入 sitemap。
- alias URL 不进入 sitemap。
- sitemap 只保留主标签 canonical URL。
- `/topics/:id` 和 `/c/:slug` 的 Go 动态 SEO 职责不变。
