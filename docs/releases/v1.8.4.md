# DevHub v1.8.4：官方插件生态与生产可用性增强

[返回文档入口](../README.md)

日期：2026-05-22

## 版本定位

v1.8.4 定义为“官方插件生态与生产可用性增强”。本版本在 v1.8.3 插件系统冻结候选基础上，优先把官方样板插件推进为可安装、可启用、可治理、可展示、可验收的生产可用插件。

本版本仍保持插件系统安全边界：不执行第三方代码，不开放 Go plugin、JS 沙箱、远程 iframe、remote component、任意远程 JS、插件市场、远程在线安装或 blocking Hook；`migrations/` 仍是唯一迁移入口，dry-run 仍不执行 SQL。

### v1.8.4-S11：Webhook 联调体验与 external_service 配置治理收口

- 后端 external_service 诊断补强：endpoint 安全拒绝、连接拒绝、网络超时、HTTP 非成功状态、token 缺失 / 无效、service disabled、plugin disabled、community plugin disabled 均补充可读 message、suggestion 和 diagnostics；保留既有 error code，不回显 token、secret 或 Authorization，diagnostics endpoint 会脱敏 userinfo 和敏感 query key。

- Docker 本地联调提示补齐：当 `http://127.0.0.1:*` 连接拒绝时，提示 DevHub 后端在 Docker 容器中时 `127.0.0.1` 指向容器自身，宿主机 receiver 应使用 `host.docker.internal`、Docker host gateway 地址或宿主机局域网 IP。
