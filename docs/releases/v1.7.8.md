# v1.7.8：Webhook 后台治理与官方公告插件端到端验证版

更新时间：2026-05-17

本轮定位：在 v1.7.7（Callback Token + Scopes + 最小 callback API）基础上，补齐 **Webhook 后台治理体验** 并提供 **官方公告插件（official_announcement）端到端验证闭环** 的最小可执行方案（仍不执行第三方不可信代码）。

> 重要边界：本轮只覆盖 non_blocking Webhook；不实现 blocking Hook；不做插件市场/动态加载/第三方代码执行；不做 OAuth/SSO。

## 本轮完成

### 1) Webhook 后台治理增强

- Webhook 治理页面补齐 Events 视图（页内 Tab，不进入左侧菜单）：
  - `Events / Deliveries / Circuits / Secrets / Callback Tokens / Callback Requests`
- 新增 Admin API：
  - `GET /api/v1/admin/plugins/webhooks/events`

### 2) 官方 mock receiver（用于端到端验证）

- 新增官方测试桩二进制：`cmd/webhook-mock-receiver`
  - 仅用于接收 Webhook、验签、注入失败（500/429/401）验证重试/熔断/签名链路
  - 不执行任何第三方插件代码
  - 不访问 DevHub 数据库

## 本轮未做 / 明确不支持

- 不支持 blocking Hook
- 不实现插件回调完整 Core API（仍仅最小：`config.read`、`audit.write`）
- 不执行第三方不可信代码，不做 Go plugin/.so 动态加载
- 不做插件市场与远程自动更新

## 检查说明

本轮为实现与治理增强任务，需执行：

- `gofmt`
- `go test ./...`
- `go build`
- `cd web/admin-app && npm run build`（建议使用 `./scripts/check-frontend.sh --admin-only`）
