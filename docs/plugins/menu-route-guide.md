# 菜单与路由指南

插件可以声明前台、后台、版主和用户中心菜单。菜单显示必须由运行时状态和权限共同决定。

## 菜单字段

- `code`：菜单编码。
- `title`：展示标题。
- `path`：前端路径。
- `area` / `location`：`frontend`、`admin`、`moderator`、`user`。
- `permission`：显示该菜单需要的权限。
- `plugin_code`：所属插件。
- `sort_order`：排序。

## 过滤规则

菜单展示必须同时满足：

1. 插件已注册。
2. 插件全局状态允许运行。
3. 当前子站启用该插件。
4. 当前用户有菜单权限。
5. 当前用户作用域匹配。

归档或禁用插件时，菜单入口应隐藏或禁用。

## 路由安全

直接访问路由仍必须由后端校验权限、插件状态和作用域。不能把菜单隐藏当成安全控制。

## 当前边界

- 当前后台使用固定 Vue 路由和通用插件内容页。
- 插件 route 声明用于治理展示和后续规划。
- 不支持外部插件动态注册前端路由或动态加载前端资源。
